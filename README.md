# 🏁 LMU RACECONTROL

**Das professionelle Race-Control-Tool für Le Mans Ultimate**

LMU RACECONTROL unterstützt die Rennkommission dabei, Vorfälle während eines Rennens **live zu erkennen, zu dokumentieren und zu entscheiden** – alles an einem zentralen Arbeitsplatz.

---

## ✨ Funktionen

| Funktion | Beschreibung |
|----------|--------------|
| 🖥️ **Live-Fahrerfeld** | Echtzeit-Timing aller Fahrzeuge – Position, Klasse, Fahrer, Team, Geschwindigkeit, Status |
| 🚨 **Automatische Vorfall-Erkennung** | Erkennt mögliche Crashes, Auffälligkeiten und langsame Fahrzeuge automatisch |
| 🔍 **Investigation-Fenster** | Vorfälle prüfen, Fahrer zuordnen, Entscheidungen treffen und dokumentieren |
| 📹 **Replay & Kamera-Steuerung** | Vorfälle direkt im Replay ansehen – mit Vor-/Nachlaufzeit und Kamerawechsel |
| 🟡 **Full Course Yellow (FCY)** | Countdown + automatische Tempolimit-Überwachung |
| 💬 **Discord-Integration** | Entscheidungen automatisch in euren Discord-Kanal posten |
| 📦 **Archiv** | Alle entschiedenen Vorfälle zentral gespeichert (26 Stunden) |
| 🌍 **Zweisprachig** | Deutsch & Englisch |

---

## 🚀 Installation

1. Lade den Installer von der [Releases-Seite](https://github.com/FOKALiS/LMU-Racecontrol/releases) herunter
2. Führe die Setup-Datei aus und folge den Anweisungen
3. Starte LMU RACECONTROL
4. Gib deinen **Lizenzschlüssel** ein (erhältst du per E-Mail nach dem Kauf)

> **Hinweis:** Eine gültige Lizenz ist erforderlich. Noch keine? Das Angebot findest du auf unserer Website.

---

## 🎮 Erste Schritte

1. **Le Mans Ultimate starten** und als Zuschauer (Spectator) auf dem gewünschten Server joinen
2. In der App links auf **"Connect to Server"** klicken
3. Sobald die Verbindung steht (Button wird grün), ins **"Fahrerfeld"** wechseln
4. Vorfälle werden automatisch erkannt – einfach auf **"Investigate"** klicken

---

## ⌨️ Tastenkürzel

| Taste | Funktion |
|-------|----------|
| `F6` | Replay Stop |
| `F7` | Rückwärts |
| `F8` | Schnell Zurück |
| `F9` | Vorspulen |
| `F10` | Slow-Motion |
| `F11` | Play/Pause |
| `R` | Replay öffnen |

---

## ⚙️ Einstellungen

- **Vorfall-Kategorien** – eigene Kategorien für das Investigation-Fenster
- **Entscheidungs-Optionen** – eigene Entscheidungen der Rennkommission
- **Discord-Webhook** – für automatische Benachrichtigungen bei Entscheidungen
- **FCY-Parameter** – Geschwindigkeitslimit & Countdown
- **LMU-Tastenbelegung** – wird automatisch aus der `keyboard.json` ausgelesen

> Die Einstellungen gelten pro Rechner und müssen auf jedem Kommissars-PC einmal eingerichtet werden.

---

## 🛠️ Systemanforderungen

- **Betriebssystem:** Windows 10 / 11 (64-Bit)
- **Spiel:** Le Mans Ultimate (installiert & aktualisiert)
- **Netzwerk:** Verbindung zum LMU-Server (als Zuschauer)
